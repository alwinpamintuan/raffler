# Self-hosted fonts

- IBM Plex Sans: variable Latin WOFF2, weights 400–700, SIL Open Font License.
- PT Serif: regular Latin WOFF2, SIL Open Font License.
- Open Sans Condensed: bold Latin WOFF2, Apache License 2.0.

Files originate from Google Fonts. License texts are included here and in
`public/font-licenses` for production distribution. CSS fallback stacks cover
glyphs outside these subsets. Build assets are precached for offline use.
